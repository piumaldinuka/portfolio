# 🚀 My Personal Portfolio

Welcome to my personal portfolio repository! This website showcases my projects, skills, experiences, and a little bit about who I am. 

The live site is automatically deployed and hosted via **GitHub Pages**.

---

## 🛠️ Built With

This portfolio is built to be lightweight, fast, and responsive:
* **HTML5** - Structuring the web content
* **CSS3** - Styling and responsive layout design
* **GitHub Actions** - Automated CI/CD deployment pipeline
